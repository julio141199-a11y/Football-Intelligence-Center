## Mandatory workflow
1. Read PROJECT.md, TASKS.md, QUALITY.md, and recent CHANGELOG.md
2. Inspect current repository data
3. Research relevant vacancies
4. Verify against official sources
5. Assess impact
6. Plan the smallest safe change
7. Modify only necessary files
8. Validate JSON, duplicates, dates, URLs, and site compatibility
9. Review the diff
10. Commit
11. Update TASKS.md and CHANGELOG.md
12. Report only meaningful outcomes

## Rules
- Track only Head Coach, Assistant Coach, and Fitness Coach within PROJECT.md organisation scope
- Never fabricate vacancies, contacts, requirements, salary, or licence recognition
- Never publish rumours as verified
- Preserve existing records unless correcting them with stronger evidence
- Use `To Verify` or omit uncertain information
- Do not edit index.html, style.css, or data.js during routine data updates unless required to prevent breakage
- Never expose secrets or private contact data
- Daily data commit messages begin with `FIC daily update:`
